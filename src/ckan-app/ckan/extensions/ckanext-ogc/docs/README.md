# OGC Documentation

This directory contains all documentation for the OGC extension.

## Documentation Structure

### `main/` - Main Documentation
- **`README.md`** - Main OGC integration documentation
- **`QUICKSTART.md`** - Quick start guide
- **`OGC-ARCHITECTURE.md`** - Architecture overview
- **`OGC-INTEGRATION.md`** - Integration details
- **`OGC-INTEGRATION-COMPLETE.md`** - Complete integration summary
- **`OGC-PLUGIN-SUMMARY.md`** - Plugin summary
- **`OGC-FILES-ORGANIZATION.md`** - Files organization

### `archive/` - Historical Documentation
- **`README-OGC.md`** - Historical manual workflow documentation
- **`ogc-plugin.conf`** - Historical configuration file
- **`README.md`** - Archive notes

## Usage

The main documentation provides comprehensive information about:

- OGC integration architecture
- Plugin functionality
- Configuration options
- Usage examples
- Troubleshooting guides

The archive contains historical documentation that is no longer current but kept for reference.
